# Aether v1.1.0

## 本次更新

- 重构全部设置页的导航与内容组织：启动方式、权限状态和本机数据入口集中展示；快捷操作默认为规则列表，支持展开编辑；服务配置使用对齐字段，保存栏固定在底部。
- 倒计时使用时／分／秒菜单；护眼提醒在一行选择工作时长、休息时长和开关，保留已有自定义时长。设置正文保持可读字号，支持深浅色、窗口记忆和可滚动详情。
- 菜单栏改为首页与功能入口，整合剪贴板、快捷操作、备忘录、提示词优化、计时护眼和端口摘要；入口可排序，返回首页保留草稿，关闭面板后优化请求继续。
- 剪贴板增加常用内容与背景图片设置，支持本机持久化、预览、缩放、对齐和透明度调整。
- 改进应用唤醒、普通窗口跨屏整理、最小化窗口恢复选项和刘海计时布局。
- 业务核心接入 Rust，保留原生 SwiftUI/AppKit 页面及平台交互；加强配置保存、历史格式兼容、失败保护及隐藏页面的资源释放。

## 下载与升级

- `Aether-1.1.0-macOS-universal.zip` 包含 arm64 与 x86_64，要求 macOS 14.6 或更高版本。退出旧版后，解压并将 `Aether.app` 放入 Applications。
- 配置、历史和背景资源保存在本机，替换应用包不会主动清空这些数据。重要数据可先按 README 备份。
- **提示词 API Key 改为本机私有文件存储，不再访问钥匙串。**旧钥匙串记录不会自动读取或删除；从旧版升级后，需要在“设置 → 提示词优化”重新填写并保存密钥。文件权限为 0600，数据目录权限为 0700；密钥是本机明文，不提供云同步。
- 提示词优化仅在主动执行时向自行配置的服务发送当前输入和优化规则。全局按键及跨应用操作需要辅助功能或输入监控权限。
- 应用使用本地代码签名证书，未进行 Apple Developer ID 公证；其他 Mac 可能出现系统安全提示。
- 附 `SHA256SUMS.txt`，用于校验下载包完整性。对应源码由本发布的 `v1.1.0` 标签提供。

## 验证与边界

- Rust 测试、Swift Package 测试、双架构 Release 构建、许可证检查及严格签名校验通过；本机安装完成产物一致性与唯一正式进程检查。
- 六个设置导航页面完成深浅色、默认和最小尺寸截图检查；隔离合成数据验证护眼时长选择、计时预设编辑与排序、配置导入导出、显式保存与重启保留。
- Intel 真机、多屏组合、部分跨应用操作与真实模型服务未逐一复测。快捷键规则展开时原生自动化曾出现 AX 通道错误，完整规则编辑 UI 自动化未记为通过。
- Rust 资源改善限于已记录的工作负载，不代表所有场景的 CPU、内存或能耗都降低，详见 `Docs/RustDelivery.md`。
