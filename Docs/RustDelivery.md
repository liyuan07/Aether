## 简短资源对比

同一台机器、同一份隔离 10,000 条合成文本。两版均搜索 `9999` 并核对可见结果，然后关闭完整剪贴板窗口，各采样 20 秒；运行的是正式安装路径中的签名应用。完成后恢复当前正式版本和正常实例。

| 整进程指标 | 原 Swift 核心 `8e3f9a5` | Rust 核心 `26f0bd6` | 变化 |
| --- | ---: | ---: | ---: |
| footprint 中位数 | 38.22 MiB | 33.91 MiB | -11.3% |
| footprint 采样峰值 | 48.25 MiB | 34.02 MiB | -29.5% |
| RSS 中位数 | 115.53 MiB | 107.67 MiB | -6.8% |
| CPU 单核占用 | 0.106% | 0.142% | 此低占用样本未显示 CPU 下降 |

这是一组后台常驻场景的工程观察，不是统计显著性、所有工作负载或总能耗证明。之前的短搜索场景曾显示 CPU/峰值下降但内存中位数上升，不能删去这一限制或把所有指标都描述为下降。原始样本、二进制哈希和场景记录保存在 `.build/benchmarks/final-idle-26f0bd6/`；较早短搜索对比在 `.build/benchmarks/final-resource-87a34b9/`。
