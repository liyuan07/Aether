# Aether · 以太

Aether 是原生 macOS 菜单栏效率工具，提供计时与护眼、剪贴板管理、快捷操作、备忘录和 Prompt 优化。配置与历史保存在本机，不提供账号或云同步；Prompt 优化仅在你主动点击优化时，将当前输入和优化规则发送给你配置的模型服务。

## 功能与使用

- **计时与护眼**：倒计时、护眼提醒和刘海计时显示。概览提供时分秒调节、单行常用预设和醒目的剩余时间，底部可切换刘海实时时间。
- **剪贴板**：历史搜索、收藏、分组、内容详情及复制与粘贴。
- **快捷操作**：自定义快捷键、按键映射、应用唤醒和快捷面板。
- **备忘录**：每项待办按一个 25 分钟番茄组织，可选截止时间；完成后勾选即删除。
- **Prompt 优化**：整理口述或草稿提示词，支持编辑、复制和本地历史搜索、回看与复用。
- 左键点击菜单栏图标，在概览、剪贴板、快捷操作、备忘录和 Prompt 五个分页间切换；按住顶部页面标签可调整其位置，顺序保存在本机；点击外部或按 Esc 收起。
- 按 ⇧⌘J 打开完整剪贴板窗口。自定义同组合动作优先，冲突在设置中说明。
- 菜单栏「Prompt」分页直接提供输入、优化结果和历史提示词，不另开编辑窗口；右键菜单也可定位该页。
- 右键点击菜单栏图标打开控制中心、Prompt 优化、设置，或重新启动、退出应用。
- 刘海用于显示计时状态，菜单栏图标用于打开操作面板。
- 刘海中间留空区始终对齐实体刘海，倒计时位数或护眼标签变化时，两侧内容仍留在可见区域。

自动粘贴和全局按键操作依赖相应的辅助功能、输入监控权限，可在设置的权限页检查。未授权时仍可使用本地计时及剪贴板记录、复制。

### Prompt 优化

1. 在「设置 → Prompt 优化」填写 Base URL、模型名称和 API Key，然后保存配置。接口采用兼容 OpenAI 的 Chat Completions 格式；API Key 保存在 macOS 钥匙串，可在无需鉴权的本地服务中留空。
2. 点击菜单栏第四个「Prompt」分页，在「输入」页直接打字、粘贴，或使用已有输入法的语音输入。Aether 不采集语音，也不会自动读取剪贴板。
3. 点击「优化」或按 ⌘↩，完成后在「结果」页编辑或复制。收起菜单栏后请求继续，重新打开可查看进度或结果。请求进行中可以取消；载入历史或新建会取消旧请求，避免结果覆盖当前内容。
4. 成功的优化默认保存原文、结果、时间和模型名，保留最近 200 条，可调整为 1 至 1000 条。历史支持搜索、回看、复用原文、单条删除和清空。设置可关闭后续历史保存；关闭保存不会删除已有记录。

Base URL 支持服务根地址（自动使用 `/v1/chat/completions`）、API 前缀（例如 `https://example.com/v1`、`https://example.com/api/v1`）或完整 `/chat/completions` 地址。远程服务使用 HTTPS，本机回环地址可使用 HTTP。这里支持 Chat Completions 兼容服务，不直接支持仅提供其他协议的接口。

内置提示词优先忠实保留目标、事实、约束和输出要求，去除口头语、重复与歧义，按任务复杂度整理结构。它不会替你执行原任务，不会凭空增加身份、技术方案或事实；关键缺项才用明确占位提示，避免把简短要求膨胀成固定模板。设置中可以编辑完整规则并恢复默认。

只有当前输入与优化规则会随请求发送，不附带其他历史。模型服务自行处理收到的内容；本地历史和 API Key 不进行云同步。未配置服务时可以使用编辑器与历史，优化按钮会引导完成配置。

## 本地构建与安装

需要 macOS 14.6 或更高版本，以及提供 Swift 6.2 或更高版本的 Xcode。首次获取依赖需要网络。

```sh
sh LaunchAether.command
```

脚本依次运行测试、构建 Release、签名并安装到 `/Applications/Aether.app`，随后检查签名、可执行文件一致性和唯一正式进程。Bundle ID 为 `com.liyuan.aether`。构建和签名失败时不会替换正式安装，安装失败时会尝试恢复此前副本。

本地签名默认使用钥匙串中的 `Ice Local Code Signing` 身份。其他开发环境可指定已有的代码签名身份：

```sh
AETHER_SIGNING_IDENTITY="你的代码签名身份" sh LaunchAether.command
```

测试和构建日志位于 `.build/logs/`。不要直接运行构建目录中的应用，以免产生重复实例。

## 本地数据

应用数据位于 `~/Library/Application Support/Aether/`，剪贴板、快捷操作、备忘录和提示词分别使用 `Clipboard/`、`Shortcuts/`、`Memo/`、`Prompt/` 子目录。备忘录和 Prompt 历史采用带版本的本地文件；Prompt API Key 单独保存在钥匙串。偏好由 Aether 自己的偏好域管理，登录启动统一在通用设置中控制。

备份时先正常退出 Aether，并同时保留数据目录和相关偏好；只复制应用包不能备份历史与配置。数据格式变更必须保留原数据并支持失败重试，具体维护要求见架构说明。

### 应用快捷键跨屏移动

应用启动器（如 Option+C）和自定义应用快捷键会把目标应用的普通窗口移到**按下快捷键时鼠标所在的显示器**；控制中心的应用按钮使用点击时鼠标所在的屏幕。启动器长按选择应用、等待启动期间移动鼠标，不会改变目标屏幕。已在目标屏幕的窗口保持原布局；跨屏窗口尽量保留尺寸与相对位置，必要时缩小以适应可用区域。多个窗口汇聚时，在空间允许的情况下错开完全重叠的位置。

已运行的应用只处理本次捕获的窗口，先移动并确认位置，再恢复最小化窗口、选择普通窗口并激活。准备最多等待 350 毫秒；超时或失败后停止发起后续移动，按当前位置唤起并说明结果。不会在唤起后继续纠正旧窗口。最小化窗口如果无法先移动到位，会保持最小化并提示失败。

未运行应用先在后台打开；重新打开无窗口应用或执行“新建窗口”时，最多等待 1.5 秒，收集首次出现后 120 毫秒内的一批窗口，随后固定处理范围。用户继续按键、点击、滚动或切换到其他应用，会取消旧请求；过时的启动回调不会主动抢焦点。“新建窗口”确认目标应用位于前台后，将 Command+N 限定发送给该进程。

在「设置 → 快捷操作 → 应用唤醒」可关闭「唤起时恢复最小化窗口」，此时最小化窗口保持原位；每个应用也可以单独选择恢复、保留最小化窗口，或仅激活、不移动。旧配置默认保留恢复最小化窗口的行为，新增选项不会重置原有应用顺序、默认应用或快捷键。

窗口在各屏的布局仅记录在本次 Aether 运行的内存中，返回原屏时优先恢复该屏的尺寸和位置。设置及控制中心的快捷操作页提供「恢复上次跨屏布局」，可恢复上一批窗口的位置、尺寸和最小化状态；原显示器断开时保留记录供重试。记录不包含窗口标题或文档内容，退出 Aether 后清空，关闭的窗口不再恢复。

此功能需要辅助功能权限，使用 macOS 公开辅助功能接口。原生全屏窗口保持原位；混合窗口时优先选择普通窗口，只有全屏窗口时仅激活应用。浮动工具窗和对话框不单独移动，正常跳过不弹提示。没有常驻窗口轮询。权限不足、显示器断开、应用不响应或拒绝操作时会显示不抢焦点的说明；其他 Space 和应用自身动画的支持取决于系统与应用，不使用私有 Space 接口。停止请求不能撤回目标应用已经接受但延迟应用的操作。

文件夹、终端路径、按键映射和窗口分区保持原行为；旧应用快捷键到 Aether 内部页面的迁移路由保持有效。
