# Aether · 以太

Aether 是原生 macOS 菜单栏效率工具，提供计时与护眼、剪贴板管理、快捷操作、备忘录和 Prompt 优化。配置与历史保存在本机，不提供账号或云同步；Prompt 优化仅在你主动点击优化时，将当前输入和优化规则发送给你配置的模型服务。

## 功能与使用

- **计时与护眼**：倒计时、护眼提醒和刘海计时显示。概览提供时分秒调节、单行常用预设和醒目的剩余时间，底部可切换刘海实时时间。
- 在「设置 → 剪贴板 → 背景图片」选择静态 PNG、JPEG、HEIC 或 TIFF，支持实时预览、图片或窗口比例适配、三种缩放、九宫格对齐和图片透明度。透明度 0% 完全可见，100% 完全透明；文字和按钮不随图片变透明。
- **剪贴板**：历史搜索、收藏、分组、内容详情及复制与粘贴；完整窗口顶部右侧的「常用内容」可长期保存手工录入的文本。
- **快捷操作**：自定义快捷键、按键映射、应用唤醒和快捷面板。
- **备忘录**：轻量本地待办，可选截止时间；完成后勾选即删除。
- **Prompt 优化**：整理口述或草稿提示词，支持编辑、复制和本地历史搜索、回看与复用。
- 左键点击菜单栏图标，在概览、剪贴板、快捷操作、备忘录和 Prompt 五个分页间切换；按住顶部页面标签可调整其位置，顺序保存在本机；点击外部或按 Esc 收起。
- 按 ⇧⌘J 打开完整剪贴板窗口。顶部右侧的「常用内容」支持搜索、单击复制、内嵌新增和编辑；新建会自动命名为「常用 1」「常用 2」等。自定义同组合动作优先，冲突在设置中说明。
- 菜单栏「Prompt」分页直接提供输入、优化结果和历史提示词，不另开编辑窗口；右键菜单也可定位该页。
- 右键点击菜单栏图标打开控制中心、Prompt 优化、设置，或重新启动、退出应用。
- 刘海用于显示计时状态，菜单栏图标用于打开操作面板。
- 刘海中间留空区始终对齐实体刘海，倒计时位数或护眼标签变化时，两侧内容仍留在可见区域。

自动粘贴和全局按键操作依赖相应的辅助功能、输入监控权限，可在设置的权限页检查。未授权时仍可使用本地计时及剪贴板记录、复制。

### Prompt 优化

1. 在「设置 → Prompt 优化」填写 Base URL、模型名称和 API Key，然后保存配置。接口采用兼容 OpenAI 的 Chat Completions 格式；API Key 保存在本机私有文件，不需要系统密码，可在无需鉴权的本地服务中留空。
2. 点击菜单栏第四个「Prompt」分页，在「输入」页直接打字、粘贴，或使用已有输入法的语音输入。Aether 不采集语音，也不会自动读取剪贴板。
3. 点击「优化」或按 ⌘↩，完成后在「结果」页编辑或复制。收起菜单栏后请求继续，重新打开可查看进度或结果。请求进行中可以取消；载入历史或新建会取消旧请求，避免结果覆盖当前内容。
4. 成功的优化默认保存原文、结果、时间和模型名，保留最近 200 条，可调整为 1 至 1000 条。历史支持搜索、回看、复用原文、单条删除和清空。设置可关闭后续历史保存；关闭保存不会删除已有记录。

Base URL 支持服务根地址（自动使用 `/v1/chat/completions`）、API 前缀（例如 `https://example.com/v1`、`https://example.com/api/v1`）或完整 `/chat/completions` 地址。远程服务使用 HTTPS，本机回环地址可使用 HTTP。这里支持 Chat Completions 兼容服务，不直接支持仅提供其他协议的接口。

内置提示词优先忠实保留目标、事实、约束和输出要求，去除口头语、重复与歧义，按任务复杂度整理结构。它不会替你执行原任务，不会凭空增加身份、技术方案或事实；关键缺项才用明确占位提示，避免把简短要求膨胀成固定模板。设置中可以编辑完整规则并恢复默认。

只有当前输入与优化规则会随请求发送，不附带其他历史。模型服务自行处理收到的内容；本地历史和 API Key 不进行云同步。未配置服务时可以使用编辑器与历史，优化按钮会引导完成配置。

## 本地构建与安装

需要 macOS 14.6 或更高版本，以及提供 Swift 6.2 或更高版本的 Xcode、Python 3（构建时校验 Rust 依赖声明）。首次获取依赖需要网络。业务核心逐步迁入 Rust，页面继续使用原生 SwiftUI/AppKit；计时状态机、搜索评分、快捷键策略、默认规则目录与版本升级、规则身份索引/编辑/重排与规则文件/配置归档编解码与归档版本判定、双文件保存恢复及过期快照拒绝、校验及执行资格快照、应用动作取消/截止/激活策略、应用排序/分组/默认选择与种子策略、偏好迁移策略/编解码与输入法切换状态机、窗口几何与布局记忆/撤销/焦点选择/候选冻结与初始布局/移动进度策略、端口连接生命周期/历史曲线/USB 拓扑/SMC 充电归属/USB-C 与非 USB-C 电源应用/控制器选择/名册规划/身份修复与 PD 交叉校验/传输关联/端口状态解码、备忘录业务、剪贴板历史/收藏/调度策略与归档校验/覆盖保护、常用剪贴板记录/搜索排名/持久化、Prompt 协议/历史策略/版本化存储、解码记录直接桥接及设置凭证回滚协调与通用文件层已接入；剪贴板保存后的资源引用选择和清理计划由 Rust 管理，保存失败不清理负载；剪贴板历史读取兼容原生解码器接受的 UTF-8/UTF-16/UTF-32 编码，读取不改写旧文件；当前迁移范围与剩余工作见 [Rust 重构记录](Docs/RustMigration.md)。

构建另需 rustup 管理的 Rust 1.90.0（仓库锁定版本）；Release 支持 arm64 与 x86_64，首次准备：

```sh
rustup toolchain install 1.90.0 --profile minimal
rustup target add --toolchain 1.90.0 aarch64-apple-darwin x86_64-apple-darwin
```

```sh
sh LaunchAether.command
```

脚本依次构建 Rust 静态核心、运行 Rust 和 Swift 测试、构建 Release、签名并安装到 `/Applications/Aether.app`，随后检查签名、可执行文件一致性和唯一正式进程。Bundle ID 为 `com.liyuan.aether`。构建和签名失败时不会替换正式安装，安装失败时会尝试恢复此前副本。

本地签名默认使用钥匙串中的 `Ice Local Code Signing` 身份。其他开发环境可指定已有的代码签名身份：

```sh
AETHER_SIGNING_IDENTITY="你的代码签名身份" sh LaunchAether.command
```

测试和构建日志位于 `.build/logs/`。不要直接运行构建目录中的应用，以免产生重复实例。

## 本地数据

应用数据位于 `~/Library/Application Support/Aether/`，剪贴板、快捷操作、备忘录和提示词分别使用 `Clipboard/`、`Shortcuts/`、`Memo/`、`Prompt/` 子目录。常用内容保存在 `Clipboard/quick-maps.json`，采用带版本的原子本地文件，不受历史数量与过期清理影响，只能由用户主动删除；标题和内容均为本机明文，请自行评估敏感内容。备忘录和 Prompt 历史同样采用带版本的本地文件；Prompt API Key 单独保存在 `Prompt/api-key.txt`，为本机明文，目录/文件权限为 0700/0600，不进行云同步或钥匙串密码验证。旧钥匙串记录不自动读取或删除，升级后请重新填入并保存 API Key。偏好由 Aether 自己的偏好域管理，登录启动统一在通用设置中控制。

背景图片独立复制到 `Clipboard/Backgrounds/`，不依赖原图片或旧 Clipboard 仓库，不受历史清理影响。已完成初次数据迁移的安装会补充导入旧 Clipboard 的背景图片和设置；已有 Aether 背景设置优先，失败保留原数据并支持重试。

备份时先正常退出 Aether，并同时保留数据目录和相关偏好；只复制应用包不能备份历史与配置。数据格式变更必须保留原数据并支持失败重试，具体维护要求见架构说明。

### 应用快捷键跨屏移动

应用启动器（如 Option+C）和自定义应用快捷键会把目标应用的普通窗口移到**按下快捷键时鼠标所在的显示器**；控制中心的应用按钮使用点击时鼠标所在的屏幕。启动器长按选择应用、等待启动期间移动鼠标，不会改变目标屏幕。已在目标屏幕的窗口保持原布局；跨屏窗口尽量保留尺寸与相对位置，必要时缩小以适应可用区域。多个窗口汇聚时，在空间允许的情况下错开完全重叠的位置。

已运行的应用只处理本次捕获的窗口，先立即激活，再在后台移动并确认普通窗口的位置，随后恢复最小化窗口、选择普通窗口。准备最多等待 350 毫秒；超时或失败后停止发起后续移动，按当前位置保持唤起状态。不会在唤起后继续纠正旧窗口。最小化窗口如果无法先移动到位，会保持最小化；窗口整理失败只停止整理，不显示屏幕浮层。

已运行应用先立即激活，再在后台整理普通窗口；全屏窗口保持原位，不因窗口整理阻塞切换。未运行应用先在后台打开；重新打开无窗口应用或执行“新建窗口”时，最多等待 1.5 秒，收集首次出现后 120 毫秒内的一批窗口，随后固定处理范围。等待结束或整理失败均只停止对应的窗口操作，不显示屏幕浮层；用户继续按键、点击、滚动或切换到其他应用，会取消旧请求；过时的启动回调不会主动抢焦点。“新建窗口”确认目标应用位于前台后，将 Command+N 限定发送给该进程。

在「设置 → 快捷操作 → 应用唤醒」可关闭「唤起时恢复最小化窗口」，此时最小化窗口保持原位；每个应用也可以单独选择恢复、保留最小化窗口，或仅激活、不移动。旧配置默认保留恢复最小化窗口的行为，新增选项不会重置原有应用顺序、默认应用或快捷键。

窗口在各屏的布局仅记录在本次 Aether 运行的内存中，返回原屏时优先恢复该屏的尺寸和位置。设置及控制中心的快捷操作页提供「恢复上次跨屏布局」，可恢复上一批窗口的位置、尺寸和最小化状态；原显示器断开时保留记录供重试。记录不包含窗口标题或文档内容，退出 Aether 后清空，关闭的窗口不再恢复。

此功能需要辅助功能权限，使用 macOS 公开辅助功能接口。原生全屏窗口保持原位；混合窗口时优先选择普通窗口，只有全屏窗口时仅激活应用。浮动工具窗和对话框不单独移动，正常跳过。没有常驻窗口轮询。权限不足、显示器断开、应用不响应或拒绝操作时停止窗口整理，但不显示屏幕浮层；其他 Space 和应用自身动画的支持取决于系统与应用，不使用私有 Space 接口。停止请求不能撤回目标应用已经接受但延迟应用的操作。

文件夹、终端路径、按键映射和窗口分区保持原行为；旧应用快捷键到 Aether 内部页面的迁移路由保持有效。

### 实时端口监测

概览的「端口」卡片显示活动端口、已报告的输入／输出功率及设备摘要；点击进入现有设置窗口的「端口」页，查看 USB-C、Thunderbolt、MagSafe、线缆、通道、充电及系统累计计数。协商速率不是实测吞吐量，系统计数不构成硬件故障诊断。

仅在概览或端口详情可见时采集；收起、切换页面、最小化、隐藏应用或系统休眠后停止。最近 60 秒功率图仅保留内存中的实际采样时段，暂停与缺失数据留空。此功能无网络请求，不保存设备序列号或端口历史，不要求管理员权限或驱动。Intel 和缺少端口控制器数据的机型显示能力限制，无法读取不等同于零。

端口核心与 IOKit 读取源码来自 MIT 许可的 [WhatPort](https://github.com/darrylmorley/whatport)，固定版本 `e6727567d0a08ccd9eac7a41cce64e9e5a6cca20`；公开仓库不含付费 Flight Recorder。Aether 的采集生命周期及界面为本项目适配，后续升级需复核多端口归属、SMC ABI 和能力降级测试。

端口采样每轮复用一次电池属性读取，并在采样后释放桥接临时对象。正式安装的整应用资源采样方法见 [资源测量](Docs/ResourceMeasurement.md)，当前不以局部微基准推导整体内存或能耗收益。

## Rust 业务核心

Rust 搜索索引的 Unicode 字符边界按片段长度采用无损整数压缩，减少短文本索引的常驻存储；评分、排序与原生字符语义保持不变，整应用收益仍需同负载复测。

搜索文档与分组合并由 Rust 持有不可变片段，Swift 缓存只保留文档句柄，避免长期保留片段包装对象和桥接指针数组。原生标准化、页面和搜索排序保持原有行为。

搜索结果以分数、日期和来源索引在 Rust 中稳定排序，再装配原生条目；排序阶段不复制完整剪贴板条目或分组。

剪贴板搜索的多片段文档评分在 Rust 中聚合，减少跨语言调用；搜索结果排序和原生页面保持不变。

剪贴板归档读取与保存由 Rust 解析、校验和序列化，Swift 保留原生页面模型与 Unicode 预览；保存采用紧凑记录和共享 UTF-8 缓冲区逐条编码，避免中间完整记录副本。磁盘字节与已校验的新输出完全相同时跳过重写，外部不同内容仍完整校验，损坏文件继续保留。保存格式和本机数据路径保持不变。

端口的设备分组、显示器/统计/线缆关联及 MagSafe 健康来源由 Rust 选择；USB 主设备和附加数量随设备数组更新一次，页面读取复用值缓存。

通用与计时偏好通过 `AppEnvironment.appDefaults` 统一管理，普通运行继续使用原应用偏好域；测试使用独立域，为固定负载资源测量提供隔离基础。

固定负载性能配置可用 `Scripts/create-resource-profile.py` 生成合成数据，通过显式 `AETHER_RESOURCE_PROFILE` 选择独立目录、偏好域和私有粘贴板；普通启动不改变现有行为。采样工具支持剪贴板页面，传入 `--profile` 时核对合成负载哈希和实时 PID。测量范围与限制见 [资源测量](Docs/ResourceMeasurement.md)。

隔离模式重新激活应用时恢复指定测量场景；剪贴板场景重复呈现会保留窗口与搜索状态，避免窗口切换误隐藏。普通模式的菜单和快捷键交互保持原有行为。

剪贴板搜索分类由 Rust 保存有序位置索引，Swift 快照共享一份条目数组；覆盖全部条目的分类直接复用数组，选择状态通过 UUID 到位置查找条目，减少重复保存完整条目。分类、排序和原生页面保持原有行为。

搜索文档中的固定类型名称片段在同一索引内共享 Rust 不可变存储；缓存上限由六种条目类型决定，不缓存任意正文。

剪贴板分组的创建/复用、成功复制后的置顶、按 UUID 删除及清空决策由 Rust 执行；保留原分组身份、日期、条目顺序和原生交互。已在首位或无变化时复用原生数组。

维护时的分组去重由 Rust 持有本次处理的指纹索引；指纹相同仍核对完整字段，保留首个有效分组、原身份与顺序。指纹不保存到磁盘，也不改变归档格式。


原 Swift 与当前版本的正式进程搜索资源对照见 [2026-10-07 记录](Docs/Benchmarks/SwiftRustSearch20261007.json)：10000 条合成文本、三组固定查询采样，CPU 中位开销降低约 12.2%，physical footprint 降低约 10.3%。该结果限于所测搜索场景，完整重构与全功能资源验收仍在进行。

配置导入和退出保存由 Rust 协调整组规则与偏好更新，只有两份均提交后才发布导入结果。更新期间可能临时生成私有恢复文件 `Shortcuts/shortcuts.json.aether-pair-journal`；正常完成后删除，意外退出后在下次加载前恢复。恢复文件损坏、版本未知或原文件被外部修改时停止写入并保留文件。日常修改仍按原有 0.25 秒延迟保存，过期快照不会覆盖新配置；内容未变的整组保存跳过文件重写。

共享数据导入的首次执行、复制后恢复、偏好重试及完成跳过由 Rust 核心协调；Swift 保留原生文件与 Property List 适配，迁移格式和原始数据保护不变。

剪贴板搜索的 UUID→索引缓存和失效清理由 Rust 持有，Swift 只执行原生文本归一化与页面装配；源更新不再构造完整 UUID Set 和 Swift 缓存字典副本。

Prompt 的配置及历史保存直接向 Rust 传递类型化记录，默认配置也由类型化桥接建立，省去 Swift JSON 编码和核心重复解析。

剪贴板面板结果的身份索引与收藏成员表由 Rust 持有，状态发布复用未改变的索引；搜索代际与结果版本也由核心维护。

剪贴板条目激活的来源优先级、分组合并文本资格和后台维护的精确来源身份判断由 Rust 协调，原生层执行剪贴板写入及记录发布。

应用路由就绪策略、旧应用跳转优先级、快捷操作的激活/重开/新建窗口跟进资格及显示桌面快捷键回退由 Rust 核心决定，Swift 保留系统查询、窗口与事件执行。

快捷操作启动的恢复、默认配置回退、规则升级及失败时保留原规则由 Rust 协调；迁移版本仅在对应保存成功后更新。

不可变搜索片段与文档使用固定长度存储，去除不需要的 Vec 容量字段；快速排除掩码缩小为 64 位，完整字符匹配和最终评分不变。

### 备忘录记录桥接

备忘录在 Rust 内持有记录并直接向 Swift 提供借用视图；Swift 在锁内复制原生 UUID、Date 和标题。保存/新增通过类型化记录进入 Rust，移除生产路径重复 JSON 编解码；磁盘版本、毫秒时间戳、排序及写入成功后发布的语义保持不变。未知版本、损坏文件和无效日期不会被部分数据覆盖。验证复用 MemoStorage 回归，并用独立 Foundation 解码确认原文件格式兼容；此变更不单独推导整机资源降幅。

### 端口快照聚合与兼容历史

端口每个快照在 Rust 中一次汇总活跃数与双向功率。旧的 60 样本历史接口由 Rust 环形缓冲保存，仅在读取时生成 Swift 数组；正式页面继续使用原分段图表历史，避免每秒复制和裁剪旧数组。

### 共享偏好与常用剪贴板记录桥接

共享导入偏好策略由 Rust 统一选择登录项和目标域、排除旧权限请求标记。常用剪贴板整库加载/保存和比较键安装改用类型化记录，避免 Swift/Rust 间整库 JSON 往返；本地格式与原生 locale 比较保持一致。
